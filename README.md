# Make the Judge Laugh in One Line

A make.fun bounty entry: one funny line, 200 characters or fewer, on any topic.

**Entry:** "My therapist told me to talk to my inner child. He asked for the Wi-Fi password and left."

`main.ts` (Node 22, stdlib only) validates the line (1-200 characters, single line, not whitespace only) and writes it to `(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`.
